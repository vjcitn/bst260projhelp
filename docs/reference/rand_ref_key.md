# Citation key for a parsed RAND reference entry

Built as surname(s) + year + disambiguation letter, e.g.
`"LottMustard1997"`, `"Lott1998a"`, `"MoodyEtAl2014"`.

## Usage

``` r
rand_ref_key(r)
```

## Arguments

- r:

  A parsed entry, as returned by
  [`rand_parse_entry()`](https://vjcitn.github.io/bst260projhelp/reference/rand_parse_entry.md).

## Value

A single character string.
